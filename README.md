# deeplearning
#in this project
# Data Loading: Loaded a dataset of 5,937 social comments labeled with three emotions (Anger, Fear, Joy).
 #Preprocessing: Normalized text to lowercase, removed non-alphabetic noise, and eliminated common English stopwords.
#Feature Extraction: Transformed the cleaned text comments into numerical vectors using a 5,000-feature TF-IDF matrix.
#Model Training: Split data 80/20 to train a Multinomial Naive Bayes model and a Linear Support Vector Machine.
#Evaluation: Evaluated models, finding that the Linear SVM outperformed the Naive Bayes baseline with 93.86% accuracy.
